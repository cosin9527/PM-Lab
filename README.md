# PM-Lab

个人产品实验室：沉淀个人项目、效率工具、AI 工作流、产品方法论与技术学习。

## 目录结构

```
PM-Lab/
├── projects/       # 个人项目
├── tools/          # 效率小工具
├── ai-workflows/   # AI 工作流与自动化
├── product-notes/  # 产品方法论与心得
├── learning/       # 技术与新知识学习
└── experiments/    # 新想法与技术实验
```

## 目录说明

| 目录 | 用途 |
| --- | --- |
| `projects/` | 完整的个人项目，每个项目独立一个子目录 |
| `tools/` | 效率小工具与脚本 |
| `ai-workflows/` | AI 工作流、Prompt 模板与自动化配置 |
| `product-notes/` | 产品方法论、心得体会与复盘笔记 |
| `learning/` | 技术与新知识的学习笔记 |
| `experiments/` | 新想法与技术实验的草稿区 |
